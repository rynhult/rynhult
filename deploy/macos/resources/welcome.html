Rynhult on this Mac: an additional machine

This installs Rynhult so that a Rynhult you already run (the main Rynhult, on Linux or Windows) can start agent sessions on this Mac.

  • A Mac is an additional machine only, not a main Rynhult (yet). The main Rynhult needs Linux: its services use systemd and separate agent accounts.
  • Sessions run as you, the user signed in now. Agents can read your files, and the node’s key and settings. If that is too much, create a separate macOS user for Rynhult, sign in as that user and install there.
  • You need Homebrew (brew.sh): Rynhult uses it to install Python, tmux, git and uv.

The files go to /Library/Application Support/ACC/src, and Rynhult Setup to Applications. When the installer finishes, Rynhult Setup opens and asks for the command from Host → Machines → Add machine on your main Rynhult. Have that page open.

This package is not signed. Rynhult is open source (MIT License).
