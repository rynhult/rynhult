# Setup levels

Choose how much navigation you normally see. A level is a personal layout choice,
saved on the server for your sign-in across browsers. It grants no permissions,
changes no Security policy and starts no agents, schedules or spending.
Setup levels are part of the [new layout](/User-Guide/New-Layout). The standard
layout doesn't show the choice.

## Choose your setup

1. On **Overview**, follow the compact **Choose what you see** prompt to
   **Settings → Setup level**, or select **Dismiss** to hide the prompt across
   browsers. Dismissal keeps your current navigation and does not mark agent or
   machine setup ready. You can always open Settings directly.
2. Select a **Setup level**. **Hobbyist** is recommended. Expand **Compare levels**
   to read all seven choices. Review **Normally visible**, **Suggested team** and
   **Quiet protections stay on**.
3. Select **Save what I see**. No level is chosen until you save one.
4. Return to **Settings → Setup level** at any time.
   **Current layout · not yet chosen** restores the complete authorized navigation.

![Setup level choices and the separate Security recommendation](/.attachments/setup-levels-desktop.png)

| Level | Normal areas in the new layout |
|---|---|
| 0 · Expert | Every authorized area. |
| 1 · Hobbyist | Overview, Inbox, Sessions, Projects, Hosts/readiness, Search, Providers, Settings and Guide. |
| 2 · Solo developer | Adds Workspaces, Grid, Schedules, Publishing and Catalog when available. |
| 3 · Small team | Adds authorized Groups, Status board and Audit. |
| 4 · Growing company | Small-team areas over the currently available operating tools. |
| 5 · Organization | The available operating and identity settings; no identity feature is enabled. |
| 6 · Enterprise | All authorized existing operational areas; automatic failover remains unavailable. |

Levels only filter the rail and **Tools** in the [new layout](/User-Guide/New-Layout).
Admin feature switches,
ownership and machine support still limit what is available at every level.
A member selecting Expert cannot see an owner's private tools or accounts.

## Find an area tucked away

Open **Tools → More tools** to reveal other authorized areas without changing
level. Saved links still work. A tucked-away page says **Not usually shown in your
layout** and offers **Change what I see**. Existing sessions, terminal access,
files, approvals, Stop, Security and recovery remain reachable. The header's
connection, Security and activity information stays visible.

On a phone, open **More**, choose **Tools**, then expand **More tools**.

## Review suggested defaults separately

The **Suggested team** text helps you choose agents in **New session**. For
example, Alex Example can choose one ready agent for a Hobbyist project on
`maple.example.lan`. Saving a layout creates no team and launches no work.
Reusable personal team profiles and automatic agent-account provisioning are Later.
Catalog profiles remain role bundles, separate from these team suggestions.

Every level recommends all eleven quiet protections **On**. Expand **See
recommended Security values** for the list. Existing inherited, customized or
locked settings remain unchanged, including choices already set Off.

Owners can select **Review matching security defaults** to open **Security**.
Choose the intended scope, inspect effective values and use its existing reviewed
apply flow for any change. Members have **View effective protections** for their
own projects. A layout recommendation is not an applied Security preset.

Expert also describes **Run Build tasks without provider permission prompts** as
an optional, separate Security review. It may remove the qualified provider's
sandbox too; it is never selected by saving Expert. Unrestricted is never a setup
default. Automatic remembered tool permission is unavailable in this setup;
account-wide changes retain the existing approval path.

## If saving fails

The inline error remains beside the choices. Check your connection and retry
**Save what I see**. A failed save does not change the
server preference or Security settings. If preferences cannot load, use **Retry**;
your existing work and full authorized navigation remain available.
