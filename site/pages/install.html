Install Rynhult

Rynhult runs on one Linux server, the main Rynhult, and you use it from a browser. Other machines can join later as nodes.

{{release.note}}

What you need

Server
Ubuntu 24.04 or newer, or Debian 13 or newer, with systemd, on amd64 or arm64.
Access
Your own user account on the server, with sudo.
Network
Rynhult answers private addresses only: your LAN, a VPN or Tailscale. To use it away from home, connect through your VPN.
Domain
Optional. With a Cloudflare zone, Rynhult gets a public certificate; without one, Caddy signs its own and you trust it on your devices.
Agents
The agent CLIs you want to run, such as Claude Code, Codex or GitHub Copilot CLI, with your own subscriptions or API keys.

Install the main Rynhult

  1. Get Rynhult's source and start the installer, acc/deploy/acc-install, with sudo.
  2. Choose Main Rynhult and answer the questions. Each shows a default.
  3. When it finishes, add the DNS entry it lists and read the one-time setup token.
  4. Open Rynhult in a browser, set up your sign-in, and sign your agent account in to its CLIs.

Each step, with every question the installer asks, is in Install → Main Rynhult on Linux. Then continue with Getting started.

Add nodes

A node runs sessions for your main Rynhult; you keep using the one dashboard. Linux machines, Macs, and Windows PCs through WSL2 can be nodes. See Additional machines and Nodes.

Use it on your phone

Open Rynhult in your phone's browser and add it to the home screen. Trust Rynhult's certificate first if it signs its own. See Connect your phone. Native apps come after v1.0.

Other platforms

A Windows main runs Rynhult inside WSL2 (Install on Windows). A Mac can be a node, but not a main yet (Install on a Mac). Other Linux distributions are test installs until they are qualified.
