Your agents. Your machines. Your call.

Rynhult is self-hosted control for coding agents. Run Claude Code, Codex, GitHub Copilot CLI and other agent CLIs on your own Linux server, and supervise them from any browser, including your phone.

One place to supervise your coding agents

You choose the agent, the project and where it runs. Rynhult starts the agent in a real terminal on your server, keeps it running when you close the tab, and tells you when it needs an answer.

  • Real agent sessions

    Each session is the agent's own CLI (Claude Code, Codex, GitHub Copilot CLI, Antigravity, Cursor or OpenCode) running in tmux. Its page is that terminal in your browser. Close the tab and the session keeps running; open it on your phone and you're back where you were.

    {{#release}}

    Sessions

    {{/release}}

  • Knows what needs you

    Sessions are grouped into Needs you, Working and Idle, with what each one is doing now. Questions, approvals and alerts collect in one Inbox, and the phone web app can send push notifications.

    {{#release}}

    Inbox and notifications

    {{/release}}

  • Nodes

    Add Linux machines, Macs, and Windows PCs through WSL2 as nodes. They connect out to your main Rynhult over a signed link, and you pick where each session runs, all in the same dashboard.

    {{#release}}

    Nodes

    {{/release}}

  • Guardrails

    Agents are stopped from force pushing, pushing to main, merging pull requests, deleting outside their workspace and reading secrets, in every permission mode. Guardrails are a safety net, not a sandbox: keep branch protection and separate agent accounts.

    {{#release}}

    Guardrails

    {{/release}}

  • Backups

    Project git backup is on by default. Owners can add encrypted backups of Rynhult's state and repositories to a Linux receiver, S3-compatible storage or a local directory. New backup schedules start off until you turn them on.

    {{#release}}

    Backups

    {{/release}}

  • Groups

    Owners create groups and appoint maintainers. Members publish committed work to the group and launch group sessions in their own private checkouts on the main server, with a shared work board for tasks.

    {{#release}}

    Groups

    {{/release}}

  • Preview your app

    See a project's running web app inside Rynhult, next to the agent's terminal. Previews are private to the project's people; publishing a site is a separate, approved step.

    {{#release}}

    Preview

    {{/release}}

  • Containers per session Preview

    An owner can run a project's new sessions each in its own rootless container. It's off by default, switched on per project, and only available on a host that has passed the container qualification.

    {{#release}}

    Sessions in containers

    {{/release}}
